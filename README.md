# Трекер привычек (Habit Tracker Bot)

Учебный проект: бот, который помогает формировать полезные привычки, регулярно выполнять поставленные цели и отслеживать свой прогресс.

## О проекте

«Трекер привычек» задуман как Telegram-бот. Пользователь создаёт собственные привычки и задаёт для них параметры: название, периодичность, время выполнения и другие настройки. Бот помогает не забывать о запланированных действиях, позволяет отмечать их выполнение и сохраняет историю активности.

Главная задача проекта — сделать процесс формирования привычек понятным и удобным. Пользователь должен видеть, какие привычки он выполняет регулярно, какие пропускает, как меняется его результат со временем и насколько успешно он придерживается поставленных целей.

## Что уже реализовано

- Создание привычки: название, цель на день (сколько раз нужно выполнить) и категория.
- Просмотр списка всех привычек с прогрессом и категорией.
- Отметка выполнения: каждая отметка увеличивает прогресс за день.
- Отметка «пропущено» для привычки на сегодня.
- План на сегодня: список привычек с наглядными статусами.
- Категории привычек и фильтр списка по категории.
- Статистика за день: сколько привычек выполнено полностью и сколько это в процентах.
- Удаление привычки.

## Что планируется

**Основные функции**

- Расширенное создание привычки: описание, периодичность, время выполнения, дата начала и окончания
- Редактирование привычки (изменение параметров)
- Напоминания
- Приоритеты привычек
- Отдельный раздел «Статистика» (история и динамика, а не только итог за день)

**Улучшения**

- Серии выполнения привычки («огонёк» по привычкам, в том числе в сравнении с другими пользователями)
- Пропуск дня и заморозка серии
- Периодичность: каждый день, по будням, 3 раза в неделю
- Цель на период, например «30 дней»
- Геймификация: система уровней и очков

## Команды

Команды вводятся в консоли.

| Команда | Что делает |
|---|---|
| `/add` | Создаёт новую привычку. Бот по очереди спрашивает название, сколько раз в день её нужно выполнять и категорию (если нажать Enter, категория будет «Без категории»). |
| `/list` | Показывает все привычки: номер, название, прогресс `[выполнено/цель]` и категорию в скобках. |
| `/done` | Отмечает выполнение. Бот показывает список и спрашивает номер, после чего увеличивает прогресс привычки на единицу. Когда цель на день достигнута, бот сообщает об этом. Если привычка была отмечена как пропущенная, отметка снимается. |
| `/skip` | Отмечает привычку как пропущенную сегодня. Бот показывает список со статусами и спрашивает номер. Уже выполненную привычку пропустить нельзя. |
| `/today` | Показывает план на сегодня: для каждой привычки прогресс и статус, а в конце итог «Выполнено: X из Y». |
| `/category` | Показывает доступные категории и просит ввести одну из них, после чего выводит только привычки этой категории (регистр при вводе не важен). |
| `/stats` | Показывает статистику за сегодня: всего привычек, сколько выполнено полностью и процент выполнения (округляется вниз до целого). |
| `/delete` | Удаляет привычку. Бот показывает список и спрашивает номер. |
| `/exit` | Завершает работу бота. |

Если ввести неизвестную команду, бот выведет список доступных.
